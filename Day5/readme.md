### 🛠️ Detailed Data Cleaning Steps Performed

Before building any analytical summaries or charts, the raw `student_performance.csv` dataset was processed using **Pandas** and **NumPy** to ensure high data quality and integrity. The following steps were executed:

#### 1. Structural Deduplication (`.drop_duplicates()`)
The dataset was scanned for redundant student records using the `Roll_No` field as a unique primary key identifier. Any rows sharing a duplicate `Roll_No` were dropped using:
```python
data = data.drop_duplicates(subset=['Roll_No'])
```
This step keeps individual student records unique, preventing duplicate rows from artificially skewing class averages or creating false metrics.

#### 2. Missing Value Imputation (`.fillna()`)
A check for missing values was performed across all six core course subjects (`English`, `Mathematics`, `Statistics`, `Database`, `Python`, `Machine_Learning`). Rather than using a sweeping `.dropna()` command—which deletes an entire student record and wastes valuable data—empty spaces were filled with the calculated `mean()` average of that specific subject column:
```python
data[column] = data[column].fillna(data[column].mean())
```
This approach neutralises missing data without dropping rows, keeping the dataset complete and statistically accurate.

#### 3. Column Nomenclature Standardization (`.rename()`)
To ensure smooth code syntax and consistent indexing, the column label `Machine_Learning_Marks` was renamed to a clean string wrapper:
```python
data = data.rename(columns={'Machine_Learning_Marks': 'Machine_Learning'})
```
This change aligns the column name with the format of the other subjects, making multi-column list selection more reliable.

#### 4. Calculated Feature Engineering
Two new columns were engineered to add analytical depth to the dataset:
*   **`Average_Score`**: Computed by calculating the row-wise mathematical mean across all six subjects for each student:
    ```python
    data['Average_Score'] = data[subjects].mean(axis=1)
    ```
*   **`Performance`**: Generated by passing the `Average_Score` through a custom conditional grading system to classify students into distinct academic categories:
    *   **Excellent** $\rightarrow$ $\ge 90\%$
    *   **Good** $\rightarrow$ Between $80\%$ and $89\%$
    *   **Average** $\rightarrow$ Between $70\%$ and $79\%$
    *   **Needs Improvement** $\rightarrow$ Below $70\%$

### 📊 Visualizations Created & Technical Reasoning

All charts were constructed using **Matplotlib** and **Seaborn** to translate rows of numbers into clear, readable visual patterns.

#### 1. Student Average Standings (Bar Chart)
*   **What**: A discrete bar chart mapping the individual final averages of a sample cohort (the first 15 students) along the X-axis.
*   **Why**: Plotting all 100 students would crowd the chart and render the text labels completely unreadable. Sampling a 15-student slice with rotated labels (`plt.xticks(rotation=45, ha='right')`) effectively visualises individual scores against the class baseline without cluttering the screen.

#### 2. Grade Curve Profiles (Histogram with KDE)
*   **What**: A frequency distribution plot sorting student average marks into 10 distinct score bins, overlaid with a smooth Kernel Density Estimate (KDE) line.
*   **Why**: This chart reveals the overall shape and spread of the data. It helps identify if the class scores follow a standard normal distribution or skew heavily toward specific low or high score thresholds.

#### 3. Python vs. Machine Learning Marks (Scatter Plot)
*   **What**: A coordinate plot comparing `Python` marks along the X-axis against `Machine_Learning` marks on the Y-axis, colour-coded (`hue='Performance'`) by performance category.
*   **Why**: This is the best tool for spotting trends, correlations, and clusters. It shows whether a strong performance in foundational syntax directly matches high scores in applied modeling domains.

#### 4. Performance Category Breakdown (Pie Chart)
*   **What**: A circular chart illustrating the percentage share of each performance category with explicit decimal formatting (`autopct='%1.1f%%'`).
*   **Why**: It provides a clear snapshot of the overall cohort balance, making it easy to see what portion of the class is in safe academic standing versus those requiring attention.

#### 5. Course Score Variance Boundaries (Box Plot)
*   **What**: A horizontal comparison plot showing the minimum, lower quartile, median, upper quartile, maximum, and outlier values across all six subjects simultaneously.
*   **Why**: This chart offers an efficient way to track cross-subject performance. It quickly shows which subjects have tight, consistent score spreads versus those with wide variations in student understanding.
